## Decision

Phase 0 the founder's work tool (exists); Phase 1 the framework (layers 0–2, the tool, the adapter, the eight-week test); Phase 2 the shared graph (observed state, drift, layer 3, a hosted backend, the solo tier); Phase 3 alignment (layer 4, per-signer pricing); Phase 4 views over one graph. Each phase names what it validates.

## Why

Two phases hid the distance between a framework and a business; five make each gate explicit.
