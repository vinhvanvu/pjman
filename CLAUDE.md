# pjman

This project has a pjman store at `.pjman/` and is built with pjman. Follow the `pjman` skill: read `pjman context change:<slug>` before working on a change, open decisions `proposed` before acting on a choice that forecloses options (never set one `decided`), name new work as `change:<slug>`, and set `next` before stopping. Every write to the store goes through the `pjman` command; run `pjman validate` before committing.

Example keys in docs and tests use `ABC-1234`.
